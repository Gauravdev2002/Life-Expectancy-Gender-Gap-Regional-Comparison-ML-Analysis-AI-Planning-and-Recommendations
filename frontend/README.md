# AI-Based Regional Health Inequality and Life Expectancy Intelligence System
## Frontend

### Setup

```bash
# Install dependencies
npm install

# Start development server (with hot reload)
npm run dev
# Opens at http://localhost:5173
```

### Pages & Routes

| Route | Page | Phase |
|-------|------|-------|
| `/overview` | Overview Dashboard | Phase 1 ✅ |
| `/life-expectancy` | Life Expectancy Analysis | Phase 2 |
| `/gender-gap` | Gender Gap Analysis | Phase 2 |
| `/regional` | Regional Comparison | Phase 2 |
| `/ml-analysis` | Machine Learning Analysis | Phase 2 |
| `/disease-burden` | Disease Burden | Phase 2 |
| `/ai-planning` | AI Planning Engine | Phase 2 |
| `/about` | About Project | Phase 1 ✅ |

### Folder Structure

```
src/
├── components/   # Reusable UI building blocks
├── pages/        # One file per navigation item
├── services/     # API fetch functions
└── hooks/        # Custom React hooks
```
